Screen readers get a name for every piece of header and content chrome. An image-only logo (`logo: { image, text: "" }`) names the home link after the image's `alt`, or the site title when it has none. A navigation selector's accessible name includes the option it shows ("Version: v2"), matching the language switcher. `<GithubInfo>` labels its star and fork counts. The first "Copied" after each page load is announced reliably, since the status region now registers before its first message.
