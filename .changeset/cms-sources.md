Add `contentful()`, `payload()`, and `strapi()` content source adapters to `blume/sources`. Each reads one content type or collection through the CMS's REST API — no SDK to install — maps its fields to frontmatter through the same `fields` option Sanity uses, and lowers its rich text body to Markdown: Contentful rich text (headings, marks, links, lists, quotes, tables, embedded assets), Payload's Lexical editor state (including check lists, uploads, and `block` nodes through serializers), and Strapi's Blocks field (including code blocks and images). A body held in a Markdown text field passes through as written. Setting `serializers` on `contentfulSource` or `payloadSource` writes lowered rich-text bodies as MDX, so the components they return render.

`contentful()` declares `CONTENTFUL_ACCESS_TOKEN` and reads through the Preview API with `CONTENTFUL_PREVIEW_TOKEN` under `--preview`, failing with a clear message when no preview token is set rather than sending the delivery token to the Preview API; `payload()` declares `PAYLOAD_API_KEY` and `strapi()` declares `STRAPI_API_TOKEN`, and both request drafts under `--preview` and stage them with `draft: true` — for `strapi()`, only documents that have no published version (through `status=draft` on Strapi 5, `publicationState=preview` on Strapi 4). Relative upload paths resolve against the CMS origin, `params` appends extra query parameters (`where[...]`, `filters[...]`, `fields.section`), and `blume init` offers all three when asking where your content lives.

CMS requests time out after 30 seconds instead of stalling a build, and a `params` entry can't override an adapter's own paging parameters. Lowered rich text stays prose where Markdown would read it as syntax: paragraph-leading `#`, `>`, `-`, `+`, and `1.` are escaped, code spans pick a delimiter longer than any backtick run inside, and link and image destinations with spaces or parentheses are wrapped in angle brackets; a paragraph that opens with `import ` or `export `, a line of only `=` or `-`, and a typed `&copy;` stay prose too. Contentful images take their alt text from the asset's description, then its title.
