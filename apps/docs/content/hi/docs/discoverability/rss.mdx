---
title: RSS फ़ीड
description: >-
  प्रत्येक दिनांकित कंटेंट प्रकार के लिए एक फ़ीड — डिफ़ॉल्ट रूप से ब्लॉग और चेंजलॉग — जो /<type>/rss.xml पर सर्व की जाती है और फ़ीड रीडर्स को स्वचालित रूप से सूचित की जाती है।
---

Blume `rss.types` में मौजूद प्रत्येक ऐसे कंटेंट प्रकार के लिए एक RSS फ़ीड बनाता है जिसमें पेज हों — डिफ़ॉल्ट रूप से `blog` और `changelog` — जो `/<type>/rss.xml` पर सर्व की जाती है। दिनांक सहित ब्लॉग और चेंजलॉग प्रविष्टियाँ लिखने के लिए [Feeds](/docs/content#feeds) देखें।

फ़ीड के लिंक निरपेक्ष (absolute) होने चाहिए, इसलिए फ़ीड्स के लिए एक साइट URL आवश्यक है: [`deployment.site`](/docs/deployment#set-your-site-url) सेट करें, या किसी ऐसे होस्ट पर डिप्लॉय करें जिससे Blume इसे स्वयं पहचान लेता है (Vercel, Netlify, Cloudflare)। साइट URL के बिना, बिल्ड कोई भी फ़ीड जनरेट नहीं करता। `blume dev` के दौरान लोकल सर्वर का URL इसकी जगह ले लेता है, इसलिए वहाँ फ़ीड्स हर स्थिति में दिखाई देती हैं।

```ts blume.config.ts lineNumbers
seo: {
  rss: {
    enabled: true,
    types: ["blog", "changelog"],
    limit: 50,
  },
}
```

| विकल्प | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `enabled` | `true` | फ़ीड जनरेट करता है। |
| `types` | `["blog", "changelog"]` | वे कंटेंट प्रकार जिनमें से प्रत्येक को एक फ़ीड मिलती है। |
| `limit` | `50` | प्रति फ़ीड अधिकतम आइटम, नवीनतम पहले। |

Blume `<link rel="alternate">` टैग इंजेक्ट करता है ताकि ब्राउज़र और फ़ीड रीडर इन फ़ीड्स को स्वचालित रूप से खोज सकें, और उन्हें [एजेंट पठनीयता मैनिफ़ेस्ट](/docs/discoverability/agent-discovery#agent-readability) में सूचीबद्ध करता है ताकि एजेंट भी उन्हें ढूँढ सकें। प्रत्येक आइटम उस साइट पर अपने पेज के निरपेक्ष URL से लिंक करता है।
